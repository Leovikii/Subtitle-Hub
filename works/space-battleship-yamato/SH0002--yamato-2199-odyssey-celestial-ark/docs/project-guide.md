# SH0002《宇宙战舰大和号2199 星巡的方舟》项目补充规范

本文件是 SH0002 唯一可以补充或覆盖系列及仓库全局规范的文档。未列出的系列译名遵循上级 `series-guide.md`，其他事项遵循仓库全局规范；偏离系列译名必须记录用户确认。

## 1. 范围与语言

- 作品：2014 年剧场版《宇宙战舰大和号2199 星巡的方舟》，单片；
- 中文主字幕：简体中文；
- 副字幕：日语；
- 目标片源：`宇宙战舰大和号2199 星巡的方舟.mkv`；
- 不包含：2199 TV 正篇、《追忆的航海》及其他总集篇或剧场版。

## 2. 来源权威分工

### 时间轴和分段

目标视频内嵌英文 ASS 是时间边界和分段主参考，但英文文本不是日语原文或中文翻译权威。出现全局时间轴纠错底线所列严重问题时，必须回到实际音画局部修正。

### 原语文本

`ja-primary-text` 是日语正文主参考；`ja-bdsup-ocr` 保存原始 SUP 及其 OCR 文本，只用于交叉验证。OCR 与音轨或主日文文本冲突时不得直接采用 OCR。

### 中文底稿

迁入的 1.0.0 当前成品是下一轮中文工作基线。旧中文观影版、旧 SRT、脚本和历史报告只存在于冻结历史 ZIP，不得作为活动 pipeline 或覆盖当前主稿。

## 3. 本项目重点风险

- 电影包含加米拉斯、加特兰蒂斯及苏美尔号等多方专名，必须先服从系列术语表；
- 英文参考可能添加日语未明说的信息，不得用英文中转覆盖日语原意；
- 广播、外星语、画面文字和大量定位特效不能统一重置到底部；
- 当前成品仍有 `迪斯拉` 与系列规范 `德斯拉` 不一致的候选，必须逐事件核对后修改。
