# SH0001《宇宙战舰大和号2199》TV 项目补充规范

本文件是 SH0001 唯一可以补充或覆盖系列及仓库全局规范的文档。未列出的系列译名遵循上级 `series-guide.md`，其他事项遵循仓库全局规范；偏离系列译名必须记录用户确认。当前进度、问题、修改历史和人工审核结论分别以同目录对应台账为准。

## 1. 范围与语言

- 作品：TV 正篇 26 集；
- 中文主字幕：简体中文；
- 副字幕：日语；
- 目标片源：`sav1our-bd-1080p-av1`；
- 不包含：OVA、《星巡的方舟》及其他剧场版。

## 2. 来源权威分工

### 时间轴和分段

目标 `[Sav1our]` 视频内嵌英文 ASS 是时间边界、分段、画面文字位置和目标文件命名的主参考。英文文本本身不是日语原文或中文翻译权威。

### 原语文本

`ja-official-webrip-cc` 日语 WEBrip CC 是普通对白日文正文主参考，但需映射到 `[Sav1our]` 时间轴，并排除听障说话人标签、纯音效括注和语言提示。CC 与实际音轨明显冲突时必须回听。

### 中文底稿和备用来源

`zh-Hans-ja-kamigami-bilingual-fallback` 用作中文底稿、旧画面排版和检索锚点；`ja-kamigami-fallback` 只在官方日文无法可靠对应时辅助定位。诸神旧日文不得反向覆盖官方日语或实际音轨。

## 3. 本项目重点风险

- 舰名、人物名、军衔、装备、组织和系列术语不一致；
- 否定、数量、方位、军事命令和因果关系错译；
- 旧日文听写造成的连带错译；
- 英语中转造成的语义偏移；
- 为求华丽添加原文外信息，或加入吐槽、出处和无关科普；
- 无法可靠映射的日语被相邻台词强行补齐；
- 顶部通讯、外星语和真实画面文字被统一重置到底部。

系列共有译名必须遵循上级 [series-guide.md](../../series-guide.md)，不得在本项目重复建立术语表。发现既有成品与系列表不一致时先登记候选并逐事件核对，不得直接批量替换；证据不足时使用中性中文并登记问题。
