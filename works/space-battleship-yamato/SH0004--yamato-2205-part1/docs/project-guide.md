- 作品：宇宙战舰大和号2205 新的旅程 前篇 -TAKE OFF-

## 2. 来源权威分工

- 时间轴主参考：目标视频内嵌英文 ASS；实际日语音轨、波形、镜头边界优先处理明显不同步。
- 原语文本主参考：目标视频已确认的日语对白音轨 `stream 1`，通过听审确认实际语音；没有可靠的可检索日文文本源。
- 中文底稿：`zh-Hans-candidate-baseline-01` 至 `04`，仅作为待校对中文和样式参考。
- 辅助译本：目标视频内嵌英文 ASS 的提取副本，承担译义、时间轴、分段和样式辅助，不覆盖明确的日语音频原意。
- 内嵌轨语言、角色、已知缺陷：英文 ASS 为 `en` 辅助参考；日文 PGS 为 `ja` 图像参考，时间轴已知不可靠，仅在疑难点回看原图；OCR 结果不进入正式 sources，也不作为原文权威。

## 3. 本项目重点风险

- 特有错听或错译类型：日语文本 OCR 误识别、英文译本自身的解释性转写、否定/数量/对象/作战关系和人物语气。
- 术语和人物关系：服从系列 `series-guide.md`；新出现的 2205 专名须逐项核对，不按 OCR 或英文拼写直接定稿。
- 片源剪辑或字幕映射风险：Bangumi 标为剧场版但本项目按用户确认的 4 个视频分段保留 `S03E01–S03E04`；合并、拆分和画面文字须逐点检查。

## 4. 样式与特殊布局

- 正文中文样式：下一轮遵循 `SH-LAYOUT-005`；特殊字幕保留参照设计
- 副语样式：本项目不发布副语；英文和日文仅为不可发布的参考材料
- 顶部或画面文字样式：沿用底稿定位信息，但按目标视频画面和中文可读性复核
- 歌曲、多说话人及特殊场景：不得按事件数量自动合并或删除；结合音频、画面和歌词/对白功能判断

## 7. 已知限制和禁止自动处理项

- 已知限制：日语 PGS 时间轴错误；OCR 文本存在大量字符、空格、换行和专名错误；无完整可检索日文脚本。
- 必须人工判断的场景：低清语音、同音词、否定、数字、专名、技术术语、人物关系、语气词、同时对白、画面文字和歌曲。
- 禁止批量处理的内容：不得依据 OCR、英文与中文的多数票批量改写语义；不得仅按 CPS、间隔、重叠或 OCR 换行批量删译、改轴或重排。
