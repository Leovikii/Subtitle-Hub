# 来源、原语与翻译纠错规范

## 1. 分维度确定权威来源

### 1.1 时间轴证据

由高到低：

1. 目标视频实际内嵌字幕轨；
2. 目标视频音频波形、实际发声和镜头；
3. 已确认与目标视频完全同剪辑版本的外挂字幕；
4. 其他发行版字幕，仅用于人工对照，不得直接套用。

内嵌轨是时间边界和分段参考，不代表其翻译文本一定正确。

### 1.2 原语文本证据

由高到低：

1. 与实际音轨一致的官方同语种字幕或正式台本；
2. 经听辨确认的同语种字幕；
3. 多个独立听写来源的交叉结果；
4. 其他语言译本，只能辅助理解，不能替代原语。

官方字幕也可能因剪辑、听障化、审查或排版而与音轨略有差异。冲突时必须回听音轨并记录判断。

### 1.3 中文译文证据

现有中文字幕始终视为待审查译本，不视为事实来源。正式译名、系列术语表和已批准项目决策可以约束表达，但不能覆盖原语实际含义。

## 2. 翻译目标

采用“信、达、雅”的顺序约束：

1. **信**：人物、动作、否定、数量、时态、因果、语气和信息范围与原语一致；
2. **达**：符合现代简体中文表达，观众能在有限显示时间内一次读懂；
3. **雅**：语域、节奏和人物声音自然，但不得为追求文采添加原文不存在的情绪、逻辑或设定。

## 3. 必查错误类型

| category | 检查内容 |
| --- | --- |
| `mishear` | 原语听错、专名听错、同音误判 |
| `mistranslation` | 主客体、否定、数量、关系、因果或语义方向错误 |
| `omission` | 遗漏剧情相关信息、称呼、语气或限制条件 |
| `addition` | 添加原语没有的信息、解释、立场或情绪 |
| `overtranslation` | 把含混语义解释得过满，或擅自补齐未确认设定 |
| `undertranslation` | 信息过度压缩，导致逻辑、人物态度或关键术语丢失 |
| `register` | 身份、时代、军衔、敬语、粗俗程度或人物口吻不符 |
| `terminology` | 人名、地名、舰名、技术名词、组织名不统一 |
| `continuity` | 前后文指代、伏笔、重复用语或剧情信息冲突 |
| `chinese` | 病句、歧义、搭配不当、赘词、错别字 |
| `punctuation` | 标点、引号、数字和中西文混排不符合规范 |
| `segmentation` | 分轴或换行破坏语义单元 |
| `timing` | 时间轴与目标片源音画不同步 |

## 4. 纠错方法

每个高风险修改应形成证据链：

```text
目标片源时间点 → 实际音轨 → 原语字幕/台本 → 上下文 → 中文修改
```

如果证据不足：

- 不猜测；
- 保留较中性的译法；
- 在 `docs/issues.tsv` 登记待确认项；
- 说明需要哪种额外证据才能关闭问题。

### 4.1 无来源语气词与反应声

现有中文底稿中的“啊”“嗯”“哎”“哦”、笑声、叹息和其他非词汇反应不能自行构成原文证据。若可靠原语字幕和目标片源其他独立字幕均无对应内容，应按疑似添加或过度翻译处理，优先删除；不得让这类无来源事件抢占下一句入点、压缩上一句时长或制造双语重叠。

若实际音轨能够清楚确认字幕来源遗漏了反应声，可以按音轨重译并保留，但必须与真实发声边界一致，并在修改台账记录音轨依据。无法确认时不得凭旧中文范本补写。

已有原语语气词也不得机械直译。确认 `えっ／あっ／うむ／まあ` 等确实存在后，应结合英文辅助译本、上下文、说话人语气和实际停顿，选择符合中文语域的表达（或在中文无需显式呈现时省略）；同时检查感叹号、问号、省略号和叠词是否与原语功能相符。英文仅作辅助，不得覆盖日语实际含义；中文底稿的“啊”“嗯”等也不能反向证明原语存在。

## 5. 压缩和省略边界

只有在阅读速度、画面信息或镜头节奏确实无法兼容时才压缩。优先删除口头冗余而不是剧情信息，且必须保留：

- 否定和限制条件；
- 人名、称呼与说话对象；
- 数量、方位、时序、因果；
- 技术术语和剧情关键词；
- 人物语气及粗俗程度；
- 笑点、伏笔和揭示顺序。

不得通过提前显示译文泄露尚未由声音或画面揭示的信息。

## 6. 副语处理

副语的文字应以对应语种的可靠来源为准，并与中文逐事件配对。副语用于辅助核对和双语观看，不承担中文翻译的中介权威。

副语可以保留本语种必要的标点和专名形式，但视觉布局统一服从 [timing-and-layout.md](timing-and-layout.md)。
