# 简体中文字幕文本规范

## 1. 文本目标

中文必须准确、简洁、自然，并能在一次观看中读懂。优先保留人物声音和剧情信息，不追求书面腔，也不使用网络流行语替代原作时代和语域。

## 2. 流媒体极简标点

仓库默认采用统一的简体中文流媒体风格：

- 普通对白不使用逗号和句号；句内自然停顿使用一个半角空格，句末不加句号。
- 顿号和分号原则上不用；列举如果不用顿号会产生歧义，可以保留 `、`。
- 疑问必须使用全角问号 `？`；必要的强烈语气使用全角叹号 `！`。
- 不使用 `！？`、`？！`、`？？`、`！！` 等连用形式。
- 迟疑、语意未尽或声音渐隐使用 `……`，即两个 U+2026；不用三个英文句点，也不用 U+22EF。
- 被强行打断或急转使用 `——`，不用两个半角连字符代替。
- 冒号 `：` 只用于明确引语、标签或解释关系。
- 简体直接引语使用 `“”`，嵌套使用 `‘’`，引号内外不加多余空格。

画面内正式文件、代码、终端内容、标牌或已确定必须忠实复现的文本可以保留原标点，作为项目例外记录。

## 3. 空格和字符宽度

- 中文与拉丁字母、希腊字母或阿拉伯数字的语义边界使用一个半角空格。
- 完整代号、型号、坐标和专有组合内部不拆分，例如 `EX178`、`BRAVO-1`、`α-1`。
- 中文标点前后不加空格。
- 不使用全角拉丁字母或全角阿拉伯数字，除非画面复现需要。
- 不允许行首或行尾出现仅用于填充视觉宽度的空格。

## 4. 数字和单位

- 一至十的普通概数在空间允许时优先使用汉字。
- 精确时间、测量、坐标、型号、航班、章节、日期和电话号码使用半角阿拉伯数字。
- 同一数字表达内不混用汉字数字和阿拉伯数字，例如不用“5千2百”。
- 度量衡原则上采用目标观众易懂的公制；原单位对剧情有意义时保留并在必要时简短处理。
- 不擅自换算货币价值或将外币改成人民币。

## 5. 专名和术语

- 优先采用官方或系列内已批准译名。
- 外国人名需要间隔时使用全角间隔号 `·`；日语和汉字文化圈姓名按项目既定译法处理。
- 舰名、装备、组织、军衔和技术术语必须进入项目术语表并保持跨集一致。
- 同一角色的正式名、昵称和称呼必须能让观众识别其关系，不能各自机械音译。
- 标题、出版物和既有作品使用官方或通行译名；无可靠译名时登记待确认，不擅自创造正式译名。

## 6. 语言质量

必须检查：

- 主谓宾关系和修饰范围；
- 否定、反问、条件、因果与转折；
- 指代对象和上下文连续性；
- 军事命令、敬语、上下级语气和人物身份；
- 赘词、欧化句式、搭配不当和歧义；
- 粗俗程度、威胁强度和情绪是否与原语等值。

脏话和攻击性表达不得无理由美化或加重。角色重复、口头停顿和语气词只有在阅读负担确实过高时才能压缩。

## 7. 注释和补充说明

字幕不是百科注释。仅在缺少说明会妨碍理解且无法通过自然翻译解决时添加短注。短注必须：

- 与当前剧情直接相关；
- 不重复常识；
- 不包含吐槽、出处炫示或字幕组评论；
- 不遮挡主对白和关键信息；
- 在项目规范中定义样式、位置和最长宽度。
