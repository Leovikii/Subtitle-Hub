# 质量控制与发布门禁

## 1. 问题等级

| severity | 定义 | 发布处理 |
| --- | --- | --- |
| `P0` | 文件损坏、缺集、无法渲染、时间非法、错误发布内容 | 必须修复 |
| `P1` | 明确错听错译、关键信息遗漏、人物/术语错误、严重不同步或明显不可读的时间轴 | 必须修复或由项目负责人书面豁免 |
| `P2` | 标点、断句、宽度、轻微语气、一般布局问题 | 应修复；未修复需登记 |
| `P3` | 可选润色、偏好差异、低置信候选 | 可以留待后续 |

## 2. 自动检查

自动化应覆盖：

- 文件编码、ASS 区段、样式引用和事件字段；
- `[Script Info]` 字段、顺序和语言标记符合发布规范，不含 `[Aegisub Project Garbage]`、本地路径、空白工程字段或默认编辑器垃圾；
- 集数和文件命名完整性；
- 非正时长、非法时间、意外同轨重叠；
- 中文与副语事件数量、起止时间和配对关系；
- 未定义样式、不可见事件和意外隐藏文本；
- 样式与内联 `\fn` 只引用全局标准字体或项目已登记例外，正式 ASS 不含来源不明字体和 `[Fonts]` 嵌入区段；
- 禁用标点、异常空格、半角问叹号和字符混排；
- 术语表不一致候选；
- CPL、视觉宽度、CPS、持续时间和间隔候选；
- 来源覆盖和无法映射的原语事件。

自动检查只能确认结构事实或提出文本候选。脚本不得自动宣布翻译正确、语气自然或画面无遮挡。

数值候选与纠错底线必须分开报告。单独超过目标 CPS、短于约 5/6 秒或长于 7 秒，默认仍是 `candidate`；出现非法时间、非预期同轨重叠、10 个或更多中文字不足 1 秒、明显超过约 12 字符/秒、无合理依据超过 7 秒、明显错离发声或双语时间不一致时，必须按 [时间轴纠错底线](timing-and-layout.md#4-内嵌时间轴纠错底线) 升级，不能因为事件继承自内嵌轨而降级。

## 3. 人工或视听检查

以下项目必须由实际音画复核：

- 错听、同音词、说话人和画外音；
- 内嵌时间轴是否贴合发声和镜头；
- 字幕是否在同一句实际发声结束前提前消失；这项不能由 CPS 合格、文本精简或内嵌轨同样短暂来替代确认；
- 笑点、悬念和剧情信息是否提前出现；
- 快速对白是否可读；
- 中文与副语是否构成正确的一一对应；
- 顶部字幕、特效和画面文字是否遮挡人物、动作或原生文字；
- 多说话人、歌曲、外语对白和特殊排版。

如果只检查了候选时间点，就记录“候选点复核”，不能写成“全片观看通过”。

### 3.1 视觉证据传递限制

视觉复核应在本地针对候选时间点完成。AI agent 不得在聊天或对话中批量上传视频截图、连续帧、逐事件截图、联系表或其他大量图像证据，以免触发 Cloudflare CDN `413 Payload Too Large`。

- 默认在审核报告中记录集数、时间点、核对结论和本地证据路径，不在对话中嵌入图片。
- 需要保存多张截图时，放入当前轮次的 `project/workspace/temp/review/attachments/`，由报告按文件路径引用。
- 只有用户明确要求查看某个单点证据时，才可在单条消息中附加不超过 2 张经过压缩的必要截图；不得用一张超大联系表规避数量限制。
- 截图只用于辅助人工判断，不能替代原视频连续播放、音轨核对或控制面记录。

## 4. 发布门禁

新版本发布前必须满足：

- 目标集数齐全；
- P0 为 0；
- P1 为 0，或存在负责人明确豁免及理由；
- 时间轴纠错底线触发项为 0，或每项均有负责人明确豁免、音画依据和影响说明；
- 已针对“字幕早于同句发声结束”的候选完成音轨边界复核；不能只凭短时长和阅读速度候选为 0 关闭该项；
- 中文和副语配对时间完全一致；
- 自动结构检查通过；
- 纯结构标准化必须证明 `[Events]` 及其后全部字节与基线一致；样式区只允许删除通过全事件 Style 字段、`\rStyle` 和空 Style 隐式 `Default` 引用闭包证明未使用的定义，并须复核不存在未定义引用；未获独立视觉审核时不得合并、重命名或改写任何保留样式；
- 字体迁移必须分别证明样式 Fontname 和事件内联 `\fn` 只发生批准映射，其他样式参数、事件文本、时间轴和特效标签未被连带改写；长句、定位、移动、缩放、歌词和卡拉 OK 高风险事件必须完成规定范围的布局复核；
- 修改台账覆盖本轮所有实质修改；
- 进度文件反映真实完成度；
- `project.yaml`、`progress.yaml` 和相关台账如实区分机器检查与人工检查覆盖范围；临时审核报告不能成为发布后唯一保留的证据；
- `subtitles/current/VERSION` 与全部当前正式 ASS 的 `Subtitle-Hub-Version` 标记一致；已有两个或更多正式版本时，完整的 `subtitles/previous/` 存在且其中版本标记自洽；
- 自动生成的正式 ZIP 已验证，包内逐文件校验值完整且可复算；
- 发布文件未包含视频、下载定位信息、临时注释或未授权署名。

## 5. 候选与确认

检测脚本输出必须标记为 `candidate`。只有完成来源核对或音画复核后，才能将问题改为 `confirmed`；实施修改后改为 `fixed`，复核通过后改为 `verified`。

非法时间和能够由事件数据直接证明的双语时间不一致属于结构事实，可直接确认；阅读速度、对白过长、音画错位和重叠意图仍需结合文本类型或实际音画判断。触发纠错底线后的修复必须复核相邻事件，并在修改台账记录原时间、新时间、依据和复核状态。

不得把“候选数量为零”解释为作品没有任何语言问题，只能说明当前规则没有检测到对应模式。
